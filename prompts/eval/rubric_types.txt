# Criterion types
Each rubric item is presence-based or absence-based. The type is a property of the item's wording, read before looking at the response: it does not depend on the response or on whether the item is met.
- A presence-based item asks whether the response contains something: a fact, a reasoning step, a list, a recommendation, a disclaimer, a format or a tone. It is met when that content appears explicitly in the response and not met when the content is missing. Missing content makes the item not met; it does not make the item absence-based. If your explanation says that the response does not mention, state or provide what the item asks for, the item is presence-based.
- An absence-based item asks whether the response avoids something. Its wording forbids or limits: it does not claim, recommend, include, assume or fabricate X; it contains no errors or contradictions; it stays within a limit such as "only X" or "without Y". It is met only if nothing anywhere in the response violates it, so check the whole response before marking it met, and say in the explanation what you checked for and what you found.
- When a rubric item has both a presence requirement and an absence requirement, label it "absence", even when most of the item asks for content and the prohibition or limit is a single clause. Its "criteria_met" still requires both parts to be met.
- A correctness word attached to a specific required fact, such as "correctly states that X", makes a presence-based item, not an absence-based one.

Return a json object where keys are the rubric numbers (as strings) and values are the type, "presence" or "absence". Classify ALL rubric items and include an entry for each one.
